# 📘 Pengingat PR X-2

Aplikasi web sederhana buatan **Firman Raditya** untuk mencatat, mengingat, dan menyiarkan PR sekolah secara publik.

---

## 🚀 Fitur
- Tambah PR (mapel, deskripsi, dan tanggal)
- Simpan otomatis ke browser (localStorage)
- Tombol **📢 Siarankan** untuk menampilkan ke halaman publik
- Halaman publik (`siaran.html`) auto-refresh tiap 5 detik
- Desain responsif dan modern, cocok untuk laptop & HP
